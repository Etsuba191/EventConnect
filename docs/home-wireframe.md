# EventConnect – Home Page Wireframe

## 1. Header / Navigation
- EventConnect logo on the left.
- Home, Events, and About navigation links.
- Explore Events button.
- Responsive mobile navigation.

## 2. Hero Section
- Main heading: Discover Events Around You.
- Short introduction to EventConnect.
- Explore Events call-to-action button.
- Background image related to community events.

## 3. Event Categories
Display category cards:
- Technology
- Education
- Workshops
- Social Events

## 4. Featured Events
Display three event cards containing:
- Event image
- Event title
- Date
- Location
- View Details button

## 5. Upcoming Events
- Display additional upcoming events.
- Include event dates and locations.
- Provide a link to view all events.

## 6. Footer
- EventConnect logo.
- About information.
- Contact information.
- Social media links.
- Copyright information.

## Layout Structure
Header → Hero → Categories → Featured Events → Upcoming Events → Footer
