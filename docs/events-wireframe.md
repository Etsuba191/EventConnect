# EventConnect – Events Page Wireframe

## 1. Header / Navigation
- EventConnect logo.
- Home, Events, and About links.
- Explore Events button.

## 2. Page Introduction
- Heading: Discover Events.
- Short description of available community events.

## 3. Search and Filters
- Search input for event names.
- Category filter.
- Date filter.
- Location filter.

## 4. Event Listings
Display events in a responsive card grid.

Each event card contains:
- Event image.
- Event title.
- Event date and time.
- Event location.
- Short description.
- View Details button.

## 5. Empty Search Results
- Display a friendly message when no events match.
- Provide an option to clear filters.

## 6. Footer
- About information.
- Contact information.
- Social media links.
- Copyright information.

## Layout Structure
Header → Page Introduction → Search and Filters → Event Listings → Footercd
