# EventConnect – Community Events Discovery Platform

EventConnect is a community events discovery platform that helps people find, explore, and learn about upcoming events in their communities.

## Project Overview

The platform provides a simple and user-friendly way to discover community events, explore event details, and try a demo registration experience.

## Features

- Discover upcoming community events from a shared typed event catalog
- Search titles, descriptions, keywords, categories, and locations
- Filter by category, online/in-person format, and free/paid status
- View dynamic event details with invalid-event handling
- Complete a validated frontend-only demo registration
- Responsive and keyboard-friendly layouts

```bash

npm install
npm run dev
```

## Development

Run the development server:

```bash
npm run dev
```

Run lint and the production build:

```bash
npm run lint
npm run build
```
