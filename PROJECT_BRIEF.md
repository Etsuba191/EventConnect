# EventConnect – Project Brief

## 1. Project Overview
EventConnect is a community events discovery platform that helps users find, explore, and learn about upcoming events in their communities.

## 2. Project Objectives
- Make community events easy to discover.
- Display important event information clearly.
- Allow users to search and explore events.
- Provide a simple demo registration experience.

## 3. Target Users
- Students
- Community members
- Event organizers
- People interested in workshops, conferences, and social events.

## 4. Core Pages
1. Home Page
2. Events Page
3. Event Details Page

## 5. Main Features
- Featured events
- Upcoming events
- Event search
- Event categories
- Event details
- Demo registration form
- Responsive design

## 6. Technology Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Local JSON data
- Git and GitHub

## 7. Project Scope
The application will be a frontend-only project. Event information will be stored in local JSON files. Registration will be demonstrated without a real backend or database.

## 8. Expected Outcome
A responsive, user-friendly community events platform where visitors can discover events, view details, and try the demo registration feature.
